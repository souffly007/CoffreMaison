# Coffre Maison — 1.0.1

Carnet privé pour centraliser les projets de maison et du quotidien.

## Fonctionnalités

- création de projets classés (travaux, factures, jardin…) ;
- notes associées à chaque projet ;
- ajout de photos, devis et factures dans le bon projet ;
- aperçu photo plein écran ;
- lecteur PDF intégré avec navigation entre les pages ;
- titre, date, montant et artisan pour les documents ;
- export chiffré d'un projet complet ;
- sauvegarde et restauration chiffrées du coffre ;
- sauvegardes portables entre smartphone et tablette avec mot de passe dédié ;
- données textuelles chiffrées en AES-256-GCM avec une clé Android Keystore non exportable ;
- verrouillage à l'ouverture par PIN à six chiffres ou empreinte digitale ;
- verrouillage automatique après cinq minutes d'inactivité ;
- captures et enregistrement d'écran empêchés ;
- aucune permission Internet, aucun cloud, aucune publicité.

## Thèmes

Système, Clair, Sombre et CyanogenMod orange-vert.

## Compiler

Ouvrir le dossier dans Android Studio puis lancer `assembleDebug`. Java 17 est requis.
